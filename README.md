# Aplicación Móvil de Gestión y Seguimiento de Solicitudes

## 1. Integrantes del equipo

- **Tomás:** Desarrollo de interfaces, navegación y formularios.
- **Ignacio:** Persistencia local, recursos nativos, animaciones y documentación.
Tomás
## 2. Descripción del proyecto

El proyecto consiste en desarrollar una aplicación móvil para gestionar y realizar el seguimiento de solicitudes de clientes. Su objetivo es facilitar el registro, la consulta y la administración de solicitudes mediante una interfaz sencilla y organizada.

La aplicación se desarrolla para Android y busca mejorar la organización de la información y la experiencia de los usuarios.

## 3. Funcionalidades implementadas

- Interfaz visual organizada y adaptable.
- Navegación entre las diferentes pantallas.
- Formularios para registrar información.
- Validación de campos y mensajes de error.
- Gestión y actualización del estado de la interfaz.
- Almacenamiento local de información.
- Animaciones y retroalimentación visual.
- Acceso a recursos nativos del dispositivo.
- Organización del código mediante el patrón MVVM.

> Las funcionalidades enumeradas deben corresponder a características que estén implementadas y funcionando en la versión entregada.

## 4. Tecnologías utilizadas

- **Lenguaje:** Kotlin.
- **Entorno de desarrollo:** Android Studio.
- **Interfaz de usuario:** Jetpack Compose.
- **Arquitectura:** MVVM.
- **Control de versiones:** Git y GitHub.
- **Planificación del trabajo:** Trello.

## 6. Requisitos para ejecutar el proyecto

- Tener Android Studio instalado.
- Disponer de un emulador Android o un dispositivo físico compatible.
- Tener Git instalado si se desea clonar el repositorio.

## 7. Instrucciones de instalación y ejecución

1. Clonar el repositorio desde GitHub:

   ```bash
   git clone (https://github.com/nxchx-bite/Proyecto.git)
   ```

2. Abrir Android Studio.
3. Seleccionar **Open** y elegir la carpeta del proyecto clonado.
4. Esperar a que Gradle termine de sincronizar las dependencias.
5. Seleccionar un emulador o conectar un dispositivo Android.
6. Ejecutar la aplicación mediante el botón **Run**.

## 8. Control de versiones

El proyecto utiliza Git y GitHub para mantener un historial de los cambios realizados durante el desarrollo.

Los commits deben describir de manera clara y técnica cada modificación, permitiendo identificar las funcionalidades implementadas, las correcciones realizadas y la participación de los integrantes.
